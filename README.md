## How I document projects

For new research and engineering projects, I aim to include:

- A clear problem statement and motivation
- Reproducible setup instructions
- Source code, notebooks, and scripts
- Results, figures, and limitations
- Citation metadata where relevant
- Short technical notes explaining design decisions

## Repository roadmap

Future repositories will generally follow this structure:

```text
project-name/
|-- README.md
|-- docs/
|-- notebooks/
|-- src/
|-- data/
|-- results/
|-- environment.yml or requirements.txt
`-- CITATION.cff
```
